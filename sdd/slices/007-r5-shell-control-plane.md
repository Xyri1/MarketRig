## 2. Plan-time settlements

- **Layout of the root:** `package.json`, `pnpm-lock.yaml`, `vite.config.ts` (port 1420, `strictPort`, `@tailwindcss/vite`, `@vitejs/plugin-vue`), `tsconfig.json` (`strict`, `moduleResolution: bundler`), `index.html`, `src/`, `openapi-ts.config.ts`, `openapi.json` (committed; regenerated by `pnpm generate`), `.prettierrc` absent (defaults), `eslint.config.js`, `vitest.config.ts` (jsdom).
- **Scripts:** `generate` (`cargo run -q -p marketrigd -- --openapi > openapi.json && openapi-ts`), `check` (prettier `--check`, eslint, `vue-tsc --noEmit`, vitest `run`), `dev` (`tauri dev`), `build` (`cargo build --release` for the three sidecars, copy to `src-tauri/binaries/<name>-<triple>`, `tauri build`), `smoke` (slice 008).
- **Workspace:** `src-tauri/` added to `Cargo.toml` members as `marketrig-desktop`; `tauri.conf.json` per feature SPEC §5; `capabilities/main.json` with the listed permissions; icons generated once with `tauri icon` from one SVG (a plain glyph, no brand work in R5), the mobile sets deleted. Corrected while implementing C42: `tauri_build::build()` resolves `bundle.externalBin` on *every* build, not only `tauri build`, so `src-tauri/build.rs` creates an empty `binaries/<name>-<triple>` placeholder for each missing sidecar before calling it, and `pnpm build`'s copy step overwrites them with the real release binaries; and `capabilities/main.json` lists no command permissions, because a Tauri 2 capability gates plugin commands only and commands registered through `generate_handler!` on the app itself are always reachable.
- **Commands:** `read_endpoint`, `start_daemon`, `set_tray_pending` (a no-op stub until slice 008 builds the tray; the command exists so the frontend is complete), `exit_app`. `start_daemon` resolves `marketrigd` beside `std::env::current_exe()` and polls the endpoint file for a `daemon_uuid` different from the one read before spawning.
- **Composables and components:** `src/composables/{useDaemon,useEvents,useTerminal,useApprovals}.ts`; `src/components/{DeskList,DeskRow,TerminalWell,SessionHeader,RightPanel,DeskTab,TriggersTab,ApprovalsTab,ActivityTab,SettingsTab,NewDeskForm}.vue`; `App.vue` composes the three panels. ghostty-web's WASM is initialised once in `main.ts` before mount.
- **Fake daemon for Vitest:** `src/test/fakeDaemon.ts` — a `fetch` stub keyed by method and path answering fixtures shaped by the generated types, and a `FakeWebSocket` with `open`, `message`, `close(code)`; no MSW.
- **Catalog check:** a Vitest that compiles every `.vue` under `src/components` with `@vue/compiler-sfc` and fails on a text node or attribute literal (`title`, `placeholder`, `aria-label`) that is not a `t()` call or a machine token binding.
- **CI:** `.github/workflows/ci.yml` gains a `frontend` job on the same matrix: `actions/setup-node` with `24.18.0`, `corepack enable`, `pnpm install --frozen-lockfile`, `pnpm generate`, `git diff --exit-code openapi.json src/client`, `pnpm check`. The Rust job's `cargo` commands already cover `marketrig-desktop`; on Windows and macOS CI the Tauri crate builds without extra system packages.
- **Onboarding:** none beyond the Settings tab auto-selected while `GET /runtimes` shows no `AVAILABLE` row.
